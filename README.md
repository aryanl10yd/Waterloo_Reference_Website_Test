# Aryan Gupta — Interactive Portfolio

A single-page, three-route portfolio built with vanilla HTML/CSS/JS and Three.js.

## Run
Open `index.html` in a modern browser. Because the 3D scene uses CDN imports, internet access is required.

## Customize
- Replace the photo placeholder in `app.js`'s `initPhoto()` with your own image texture.
- Change the ChessInsight GitHub URL in `home()`.
- Replace social URLs/handles in `contact()`.
- Edit content directly in `home()`, `about()`, and `contact()`.

## Structure
- `#home` — purple theme + interactive PCB
- `#about` — yellow/gold theme + rotatable 3D photo card
- `#contact` — green theme + 3D-inspired hover bubbles
